How to use CtoA

apk edition · by MC88

This is CtoA APK Edition. Same engine as the web version, but running natively on Android. Files save directly to your Downloads, and notifications keep you updated.

Setup

  1. Create a GitHub token at github.com/settings/tokens/new.
  2. Scopes: repo + workflow.
  3. Paste it in Step 1. Done.

Build

  1. Upload your HTML (ZIP, HTML, or folder).
  2. Set name, package, icon.
  3. Click Build APK now.
  4. Wait 2–4 minutes. APK saves to Downloads automatically.

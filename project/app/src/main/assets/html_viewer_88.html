how to use

viewer88 · editorial os · mc88

Viewer88 reads code you paste, upload as a single file, drop as a folder, or build from scratch as a project — and renders the result instantly. Everything runs locally, no upload, no tracking.

four ways to load code

  1. Paste — drop HTML into the textarea. A single line works.
  2. File — choose a single .html, .svg, or .md.
  3. Folder — pick a whole project. Finds index.html and inlines CSS, JS, and images.
  4. Project — build a mini workspace with your own files. Edit and preview side by side.

working with a project

  1. From the Project tab, tap New project — you get index.html, style.css, app.js.
  2. Tap + File or + Folder in the tree. Paths like assets/logo.svg create nested folders.
  3. Every file auto-saves to local storage. Reopen anytime.
  4. Tap Run to render the current HTML with all CSS and JS inlined.
  5. On mobile, use Files · Edit · View to switch panels.

privacy

  1. No code leaves your browser — everything runs locally.
  2. Pasted text, projects, and history live in local storage only.
  3. Uploaded files are read in memory. They are never saved to disk.
